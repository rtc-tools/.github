# Security Policy

CRA stewardship: This project is supported under the Linux Foundation CRA
stewardship framework, as described at <https://www.linuxfoundation.org/security>.

Security vulnerabilities should be reported through the mechanisms described
below, which we will coordinate with our CRA steward. For actively exploited
vulnerabilities and severe incidents that may require CRA escalation, please use
the project's emergency security reporting mechanisms as appropriate.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use one of:

- GitHub private vulnerability reporting, where enabled: open the **Security** tab of the
  affected repository and choose **Report a vulnerability**.
- Email [info@rtctools.energy](mailto:info@rtctools.energy).

For actively exploited vulnerabilities or severe incidents, use either channel above and
mark the report as urgent.

We will assess the report and keep you updated on progress and next steps.
