# .github

Organization-level files for the [RTC-Tools](https://github.com/rtc-tools) GitHub organization.

- `profile/README.md` is the landing page shown on the [organization profile](https://github.com/rtc-tools).
- `SECURITY.md` is the default security policy for organization repositories that do not define their own.
- Other default community health files can be placed here and apply to organization repositories that do not define their own.
