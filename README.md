# RTC-Tools

RTC-Tools is an open-source Python framework for modeling, simulating, and
optimizing dynamic systems. It provides a modular, extensible foundation for
operational optimization and control of networks of assets across water
management and energy, including canals, reservoirs, pumps, hydropower systems,
batteries, and heat networks.

Build models with Python or Modelica and solve linear or nonlinear optimization
problems with continuous or discrete decisions. RTC-Tools also supports
multi-objective optimization and optimization under uncertainty, with a choice
of open-source and commercial solvers.

Learn more in the [RTC-Tools repository](https://github.com/rtc-tools/rtc-tools)
and [documentation](https://rtc-tools.readthedocs.io/).
